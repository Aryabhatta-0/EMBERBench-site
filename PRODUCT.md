# Anantam

Anantam’s tagline is always **Boundless Possibilities**. EMBERBench is its sole published contribution. Do not invent products, launches, customers or achievements. The user's latest instructions override older design reports.

The entire site is light only. The homepage uses the supplied navy emblem and local fonts. Its centered hero fills the viewport below the measured header, with no side gutters, inset rectangle, cursor tracking or pause-motion button. A static mist-blue, porcelain and ivory gradient supports the identity. Fine particles assemble into the actual emblem once, then hold permanently. Pale side contours drift continuously; there is no darker highlight moving along them. Reduced motion is static, offscreen work pauses, and the supplied emblem is the no-JavaScript/no-Canvas fallback.

The hero action opens benchmark.html directly. EMBERBench results span the browser width with open chart sections: ten-entry ranking pages, safety/quality scatter, exact people outcomes and the selected model's ten scenario bars. The page uses vertical scrolling and readable labels. No enclosing card, comparison table, comparison selector or table-format toggle appears on results. leaderboard.html is a compatibility alias. The existing separate comparison page supports deliberate multi-model analysis.

Selected model, ranking page and filters survive reload. Scenario links retain the model and scenario; profiles preserve access to supporting evidence. Search, sorting and keyboard actions are immediate. Mobile filters remain easy to reach and charts stack without horizontal page scrolling.

The homepage's two outcome pictographs encode exact published people counts. Hover separates outcome groups, while an explicit button serves touch and keyboard users. The evaluation explanation connects observation, decision and simulation with verification and scoring. The user removed evacuation maps, reference replay players and scrubbers everywhere; do not restore them.

Documentation lives at docs.html and docs/*.html, with 28 complete static guides, local full-text search, contents links and original Markdown downloads. Protocol links stay on the website. Reading works without JavaScript or the results artifact. Benchmark source revision and license are recorded. Explicit implementation-source links may open GitHub.

Published results come exclusively from site/data/results.js. Never edit that generated snapshot, scores, ranks, model identities or scientific qualifications by hand. EMBER is a family-balanced composite, not a survival percentage. Preserve the one-trial public-development limitations and missing API measurements.

Static GitHub Pages delivery needs no application server, production npm install, CDN, authentication or database. Build dependencies regenerate the hosted docs from checked-in sources. Sarvam, Gnani and Artificial Analysis informed interaction and readable research layouts; the supplied identity and current user feedback determine the final design.
