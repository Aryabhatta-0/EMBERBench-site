# Anantam

Anantam is an experimental AI company. EMBERBenchmark (the underlying research project is named EMBERBench) is its sole published contribution. Future work may happen, but do not invent products, launches, customers or achievements.

The user rejected the earlier split hero, dark mode, navy stats card, duplicate benchmark hero, and future-outlook filler. Their explicit current direction wins over any older design notes. The whole site is light only.

The homepage has two sections: a centered company introduction and a single expanding EMBERBenchmark showcase. Its centered action scrolls to the contribution. Environment, Results and Methodology are views of that contribution, not separate products. Sarvam’s actual expanding rails informed the 650ms reveal; Gnani informed the restrained product hierarchy.

Explore the benchmark opens benchmark.html, which immediately renders the searchable leaderboard. leaderboard.html remains a compatibility alias using the same module. Compare, scenarios, model profiles and methodology belong to the same site and shared navigation. There is no secondary benchmark marketing homepage.

The environment diagram uses the actual public corridor-bottleneck initial coordinates, with source attribution. Its animated line highlights the corridor and is not an evaluated model replay. Results come exclusively from site/data/results.js. Never edit that generated snapshot, score definitions, ranks, model IDs or scientific qualifications by hand.

Local fonts, the supplied navy emblem and a locally served GSAP distribution remain. Static GitHub Pages delivery needs no application build step, production npm install, CDN, authentication or database. Company text, source links and the real scenario remain available without JavaScript; animation and result-preview failures have fallbacks.
