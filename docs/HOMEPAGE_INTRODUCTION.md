# Homepage introduction and typography

Updated 27 October 2026.

The homepage introduces EMBERBench through one title, a lead description and two supporting paragraphs. It explains the simulated evacuation task, step-by-step decisions without future fire information, shared frozen environments, replay verification and the public-development scope of the results. The additional copy gives the section more presence without enlarging the type or adding another layout. Model scores, outcome displays and the evaluation stepper are removed from this introduction. There is no stock image, right-hand feature column, extra link or duplicate benchmark button. Results remain on the results page; Methodology retains its evaluation explanation.

The existing navy identity, local Instrument Serif and DM Sans fonts, full-window hero, one-time emblem assembly, continuous pale contours and asymmetric transitions remain.

## Skills applied

- **Impeccable 4.7 — typeset:** assessed title, description and supporting-copy roles. Replaced the oversized 84/38/17px combination with 56/24/18px on desktop and 44/20/16px on phones. Tuned line heights, role spacing and progressive balanced/pretty wrapping while preserving the established typefaces. The optional engine detector was unavailable because its bootstrap could not obtain the engine; rendered inspection and source/computed-style checks were used instead.
- **UI/UX Pro Max:** searched its local UX guidance for font scale, line length and leading. Applied a consistent role hierarchy, bounded reading width and body leading within its 1.5–1.75 guidance. The introduction uses a maximum 780px reading block rather than full-window prose, and rem units respect browser text sizing.
- **Taste:** applied the existing-project audit and brand-preservation guidance. Removed the decorative right-hand composition and used the supplied identity, typography and whitespace without introducing another graphic or design system.

These skills were already installed locally; no new installation was needed for this revision.
