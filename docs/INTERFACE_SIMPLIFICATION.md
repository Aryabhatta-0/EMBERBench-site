# Interface simplification

Results now begin with one compact model search and one closed Filters disclosure. Entry type, provider, ranking metric and reset appear only when requested. The stacked metric buttons, chart-jump navigation, visible result-count paragraph and duplicate model dropdown/profile shortcut have been removed. Bars and scatter points select the model directly; the selected model is named by its charts and evidence. Search, all eleven ranking metrics, filtering, ranking pagination, URL state and scientific data remain functional.

The native filter disclosure closes on Escape with focus returned to its summary, or on an outside click. Controls retain visible labels, focus outlines and touch targets. The same compact layout works on desktop and phone; no separate mobile filter arrangement is needed.

Methodology no longer shows Results / Compare / Scenarios sub-navigation or the Explore the results CTA. The shared site header, article contents and links to hosted protocol documentation remain.

Below the homepage hero, the repeated Explore button, profile arrows, Compare these models link, scoring/methodology shortcuts, duplicated promotional heading and footer navigation have been removed. The contribution keeps its identity, exact published people outcomes, grouping controls, short factual captions and evaluation explanation. There are no navigation links within the contribution. The hero retains its single benchmark CTA and current gradient/particle/pale-contour behavior.
