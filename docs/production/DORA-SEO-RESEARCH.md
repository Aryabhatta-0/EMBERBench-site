# Dora publishing research and Anantam discoverability

Checked 28 October 2026 (Asia/Calcutta). Research skill applied: inspect primary sources, distinguish observation from inference, and preserve a source-linked record. This report concerns public documentation and observable delivery, not Dora's private implementation.

## What Dora actually documents

**Observed in Dora's official SEO Settings guide:** a site-wide title/description pattern provides defaults, while individual pages can override their title, description and URL. The guide recommends concise titles and relevant descriptions and explicitly discourages keyword stuffing. Its approximate character counts are editorial suggestions, not evidence that Google enforces fixed-length limits. No automatic ranking or traffic-promotion mechanism is described. [Dora: SEO Settings](https://dora-design.notion.site/SEO-Settings-3df9c8d15c2a4ae586aeb65d2ac869c9?pvs=25)

**Observed in Dora's official publishing guide:** publishing is an explicit per-domain action. A hosted subdomain can serve staging/testing, while an owned domain is configured and verified separately before publishing. Its workflow checks DNS status and explains that unpublishing produces a default 404. These are deployment and identity controls, not evidence of search ranking gains. Both official Notion guides returned HTTP 200 through Firecrawl during this research. [Dora: Publish & Custom Domain](https://dora-design.notion.site/Publish-Custom-Domain-be8260e71892403da18d0d8a3f24b0e4?pvs=25)

**Application to Anantam (proposed):** keep one metadata system with meaningful page-specific overrides; use the existing production origin consistently in canonicals, social metadata and the sitemap; keep preview deployments separate; verify the production alias rather than assume that a successful build made it public. Do not copy Dora's DNS values, UI, wording or infrastructure assumptions.
