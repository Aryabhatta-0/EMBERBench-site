# Accessibility

Updated 28 October 2026

We aim to make Anantam's research and documentation usable with keyboards, assistive technologies, different screen sizes and reduced-motion settings. Our implementation target is WCAG 2.2 Level AA. This statement describes the work in place; it is not a certification of complete conformance.

## Using the website

A skip link moves to the main content. Navigation and form controls have visible focus states. On the benchmark page, you can search for a model, open Filters, and move through model columns with the arrow, Home and End keys. Enter or Space selects a model. People-outcome labels provide exact counts, and provider names and score labels accompany chart colours.

The website uses a light appearance, responsive vertical charts and readable documentation. Your device's reduced-motion setting stops decorative movement. Page content remains readable when JavaScript is unavailable: the homepage, policies and documentation are static, and the benchmark has a text version of its public results. Interactive filters and deeper model-analysis tools require JavaScript. Machine-readable [public results](data/leaderboard.json) and [Markdown documentation](llms.txt) provide other ways to read the evidence.

## Checks and ongoing work

We check key journeys with keyboard navigation, different phone and laptop widths, reduced motion and automated accessibility tools. Automated checks cover only part of accessibility. External websites and source repositories have their own interfaces and may behave differently. We will continue reviewing reported barriers as the site changes.
